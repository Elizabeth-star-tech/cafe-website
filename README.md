# Savanna Brew: Cafe Website

A responsive cafe website for Savanna Brew, a coffee and kitchen in Nairobi. Customers can browse the menu, build an order, and reserve a table.

## Features
- Hero image slider with arrows and dots that changes automatically
- Menu filtered by category: Coffee, Fast food, Desserts, Beverages, Special dishes
- Order panel with item count, running total in KSh, place order and clear order
- Table reservation form with validation (name, phone, email, date, time, guests)
- Reservation rules: no past dates, opening hours 7:00 AM to 9:00 PM
- Gallery with a click-to-enlarge picture viewer
- Customer reviews section (sample reviews for this demo)
- Sign up and login page
- Dark mode and light mode toggle
- Mobile-friendly navigation menu and scroll animations

## Built with
HTML · CSS · JavaScript

## Project structure
- `index.html`: main page (home, menu, about, gallery, reviews, reservation, contact)
- `login.html`: login and sign up
- `css/`: styles
- `js/`: scripts for the menu, order panel, slider, login, and page features
- `images/`: photos used on the site

## How to run
1. Download or clone this repository
2. Open `index.html` in your browser

## Notes
This is a front-end project. Data such as accounts and the theme setting is saved in the browser using localStorage, so there is no backend or database. Reservations and orders are not sent anywhere, and the login is a demo.
